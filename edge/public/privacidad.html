Quién usa DUPLA

DUPLA es una herramienta personal de Álvaro y Angie para organizar sus proyectos, planes, viajes y calendario. No es un servicio público: solo existen sus dos cuentas y no se pueden crear otras. No hay publicidad ni uso comercial.

Qué datos se guardan

  • Lo que vosotros apuntáis en DUPLA: proyectos, tareas, ideas, viajes, gastos, notas, fotos y archivos.
  • Las transcripciones y grabaciones de vuestras reuniones, solo si las iniciáis.
  • Los datos técnicos mínimos para que funcione: sesiones abiertas y dispositivos con avisos activados.

Qué datos de Google se usan

Solo con la autorización expresa de cada persona, DUPLA accede a Google Calendar para:

  • Mostrar, crear y editar eventos del calendario compartido «DUPLA · Nuestro calendario».
  • Mostrar y, si lo pedís, editar los eventos de los calendarios personales que cada uno elija fusionar.

DUPLA no accede al correo, los contactos, Drive ni ningún otro servicio de Google. El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde y cómo se guardan

En la infraestructura de Cloudflare, protegida con contraseña y sesiones seguras. Las credenciales de Google y las claves de los avisos se guardan cifradas y nunca se envían al navegador. Las funciones de IA (transcribir, resumir, sugerir) se ejecutan en Cloudflare Workers AI y no se usan para entrenar modelos.

Cómo retirar el acceso o borrar datos

  • En DUPLA: Calendario → «Dejar de fusionar» para quitar tus calendarios personales.
  • En Google: myaccount.google.com/permissions → DUPLA → Quitar acceso.
  • Cualquier dato de DUPLA se puede borrar desde la propia aplicación.
